# sdl3-image
Based on https://github.com/haskell-game/sdl2-image
#### Haskell bindings to SDL3_image
Works with `27bb32ac51467b393687b898435062d58fd2b63d` commit of sdl-image

##### Example

A small example executable is included with the library. It loads and displays
a given image. You can find it in the `example` directory.

```bash
cd sdl3-image-hs
cabal run path/to/some/image.type
```
